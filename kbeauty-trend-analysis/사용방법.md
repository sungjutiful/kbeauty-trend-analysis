# 대시보드 실행 방법

별도 서버나 빌드 없이 브라우저에서 바로 열립니다.

1. `dashboard/index.html`을 더블클릭하거나 브라우저 주소창에 파일 경로를 입력해서 연다.
2. 인터넷 연결 필요 (Chart.js, 폰트를 CDN에서 불러옴).

## 필터 사용법

- **성분 칩**: PDRN / Ectoin / Exosome 클릭 시 그래프에서 표시/숨김 전환
- **기간**: 시작일 · 종료일 선택 시 그래프와 하단 요약이 해당 구간으로 다시 계산됨
- **4주 이동평균**: 체크 시 원자료 대신 스무딩된 추세선으로 전환
- **선택 구간 요약**: 활성화된 성분의 구간 내 최고치와, 2개 이상 선택 시 성분 간 상관계수(Pearson)를 실시간 계산
